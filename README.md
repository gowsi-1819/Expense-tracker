# 💰 Expense Tracker

A responsive and interactive Expense Tracker web application that helps users manage income and expenses efficiently. The application provides real-time balance calculation, visual data representation using charts, and emotional feedback using dynamic emojis.

## 🚀 Features

- Add Income and Expense transactions
- Edit and delete transactions
- Automatic balance calculation
- Monthly expense limit setting
- Emoji indicators:
  - 😊 Income added
  - 😢 Expense added
  - 😱 Limit exceeded
- Pie chart visualization (Chart.js)
- LocalStorage support (data persists after refresh)
- Clean and responsive dark theme UI

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Chart.js

## 🎯 Key Concepts Used

- DOM Manipulation
- Event Handling
- LocalStorage
- Array & Object Handling
- Dynamic Chart Rendering
- Conditional UI Updates
